### Engineering Principles

> **Zero unnecessary bloat · Explicit guarantees · Built to run reliably in production.**

- Prefer battle-tested primitives (`AES-256-GCM`, `HMAC-SHA256`, `Argon2id`, `PostgreSQL` row locks) over hand-rolled magic.
- Build tools that run cleanly offline and locally before adding cloud complexity.
- Ship documentation, schemas, and verifiable tests alongside code.
